# NEXT.JS APP ROUTER ARCHITECTURE & FOLDER STRUCTURE RULES (OPTION 2)

## 🚨 CORE MANDATE
Setiap file BARU wajib ditempatkan sesuai dengan struktur arsitektur modular di bawah ini. DILARANG MENAMPUR logika database, validasi schema, server actions, dan UI komponen dalam satu file.

---

## 📂 PROJECT FOLDER STRUCTURE

```text
crm-student-portal/
├── actions/                  # 🚀 SERVER ACTIONS (Data Mutations & Server-side Logic)
├── app/                      # 🌐 NEXT.JS ROUTING ONLY (Pages, Layouts & Webhook API)
│   ├── (auth)/
│   ├── (dashboard)/
│   └── api/                  # ONLY for Webhooks or External REST APIs
├── components/               # 🧱 REACT UI COMPONENTS
│   ├── ui/                   # 🎨 Raw Shadcn UI Primitives (Generated by Shadcn CLI)
│   ├── forms/                # 📝 Form UI Components (React Hook Form + Shadcn UI)
│   ├── tables/               # 📊 Custom Feature Data Tables (Data display & actions)
│   └── shared/               # 🌐 Global Shared UI (Navbar, Sidebar, Footer, Modals)
├── lib/                      # 🛠️ THIRD-PARTY & INSTANCE CONFIGS (Prisma, MinIO, Utils)
├── schemas/                  # 🛡️ ZOD VALIDATION SCHEMAS & DERIVED TYPES
├── types/                    # 📐 GLOBAL TS DEFINITIONS (Non-Zod Interfaces)
└── prisma/                   # 🗄️ DATABASE SCHEMA & MIGRATIONS
🎯 FOLDER RESPONSIBILITIES & BOUNDARIES
1. actions/ (Server Actions)
Rules: Must start with "use server";. Handle data mutation (Create, Update, Delete) and DB queries.

Imports: Import Prisma from @/lib/prisma, Zod Schemas from @/schemas/.

File Naming: [feature].action.ts (e.g., student.action.ts, auth.action.ts).

2. schemas/ (Zod Schemas)
Rules: Pure TypeScript/Zod definitions. NO React/JSX code allowed.

Role: Export Zod schemas and inferred TypeScript types using z.infer<typeof schema>.

File Naming: [feature].schema.ts (e.g., student.schema.ts).

3. components/forms/ (Form Components)
Rules: Must be Client Components ("use client";).

Role: Render forms using Shadcn UI primitives (components/ui/) integrated with react-hook-form and @hookform/resolvers/zod.

File Naming: [feature]-form.tsx (e.g., student-form.tsx).

4. components/tables/ (Feature Data Tables)
Rules: Responsible for rendering data queries, column formatting, and row action buttons.

Role: Import raw UI table components from @/components/ui/table and accept data via props.

File Naming: [feature]-table.tsx (e.g., student-table.tsx, course-table.tsx).

5. components/ui/ (Shadcn UI Primitives)
Rules: DO NOT WRITE BUSINESS LOGIC HERE. These are generated by the Shadcn CLI. Only edit styling/variants if necessary.

6. lib/ (Singletons & Utilities)
Rules: Initialize global instances (Prisma Client, MinIO Client, Shadcn cn() helper).

Examples: lib/prisma.ts, lib/minio.ts, lib/utils.ts.
